## 🚀 Featured Projects

### 📸 [SnapClass: AI-Powered Biometric Attendance System](https://github.com/SilverSword98)
*A full-stack multi-modal web application designed to eliminate manual roll-calls using sub-second automated biometric verification.*
- **Computer Vision:** Built a pipeline extracting 128D facial embeddings and trained an SVC optimized for low-latency matching on small class sizes (<100 students).
- **Audio Processing:** Processed raw audio using Voice Activity Detection (VAD) to trim dead air, generating 256D voice embeddings for cosine-similarity speaker matching.
- **Backend:** Designed a PostgreSQL database schema to manage enrollments and log attendance with a strict >0.75 confidence threshold to prevent false positives.
- **Tech:** `Python`, `OpenCV`, `Scikit-Learn`, `PostgreSQL`, `Flask`

### 🏦 [CreditWise: Machine Learning Loan Approval System](https://github.com/SilverSword98)
*An intelligent decision-support pipeline designed to automatically predict whether a bank should approve or reject a customer’s loan application.*
- **Predictive Modeling:** Built a robust classification model using historical applicant and financial data.
- **Data Engineering:** Performed extensive data preprocessing, feature engineering, and EDA on customer attributes (income, credit score, DTI ratio, savings, employment status).
- **Impact:** Delivered a fast, scalable, and data-driven pipeline for automated loan approval recommendations.
- **Tech:** `Python`, `XGBoost`, `Random Forest`, `Pandas`, `Seaborn`

### 🛒 [SmartCart: Customer Segmentation & Targeted Marketing Model](https://github.com/SilverSword98)
*A customer clustering and behavioral analytics system for intelligent e-commerce segmentation.*
- **Unsupervised Learning:** Developed a pipeline using K-Means Clustering to segment 2,240 e-commerce customers based on purchasing behavior and demographics.
- **Feature Engineering:** Engineered high-value business features (Total Spend, Customer Tenure) and optimized distance-based algorithm performance using StandardScaler.
- **Evaluation:** Achieved a Silhouette Score of 0.48 using the Elbow Method, successfully identifying 4 distinct customer personas to drive personalized marketing campaigns.
- **Tech:** `Python`, `K-Means`, `Scikit-Learn`, `Data Analytics`
